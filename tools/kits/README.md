# 套件檔案產生器（試做版）

產生雷切 SVG（紅＝切割、黑＝雕刻、藍＝線刻，和創客小幫手一樣）和 3D 列印 STL，輸出在 `out/`。

| 程式 | 產生 |
|---|---|
| `tests_boards.py` | 軸孔測試尺、接頭測試板（3 mm、5 mm）：梯形榫、榫邊凸點、竹籤插銷、楔子、懸臂卡扣；十字軸測試板（軸承圓孔、十字孔） |
| `automaton.py` | 手搖招潮蟹：盒子框架（凸榫＋竹籤插銷）、兩片木條插成的十字軸、可換的凸輪（大／小／雙）、從動桿、會揮的大螯。`motion_check()` 轉一整圈檢查間隙，`render()`、`animate()` 算成品圖和動畫 |
| `maze.py` | 旋轉迷宮：圓盤迷宮（程式產生，再用重力模擬確認只靠轉圓盤走得出去）、三層迷宮層、壓克力蓋、前框、斜 12° 的架子和接珠子的盤子。`python3 maze.py` 出檔；`search_seeds()` 換迷宮、`solve_gif()` 做走法動畫 |
| `wood_car.py` | 全木小車：側板、隔板（凸榫＋竹籤插銷）、三層木輪（中間夾橡皮筋）、墊片、黑鮪魚乘客；螺絲柱版側板。加 `render` 會算成品圖 |
| `roll_car.py` | 一印出來就會滾的車：車頂朝下列印，輪軸末端的凸環卡在輪子裡；間隙 0.3／0.4／0.5 三種。`python3 roll_car.py 名字` |
| `render_roll.py` | 滾滾車的成品圖 |

參數（板厚、切縫、軸徑、插銷位置、間隙）都在各檔案最上面；學校試切後把量到的數字改進去再重新產生。
需要：`numpy scipy scikit-image pillow fonttools`，字型用思源黑體（Noto Sans CJK）。
