# 創客小幫手

創客課程用的網頁小工具，不限課程或場地。小朋友畫圖、打字、放貼紙或拍照，網站自動做成 3D 列印（STL）或雷射切割（SVG）的檔案。

- 網址：https://kenchen0728.github.io/maker-helper/
- **作品**：立牌、雕刻圖案、吊飾名牌、印章、模具、薄片、陀螺圓盤、照片雷雕、照片透光片。網址加 `#作品代號` 直接打開，例如 `#mold`（模具）、`#stampW`（印章）、`#engrave`（雕刻圖案）。作品卡片圖（`works/`）是用網站產生的作品幾何算出來的成品圖：牛皮紙桌面、暖色燈光、同一個角度；作品上的圖案和打開作品時的範例圖是同一張小朋友手繪風的圖（程式畫的）。照片作品的範例照片是程式畫的虛構海景。重做卡片圖的方法在 `tools/card-images/`。
- **照片**：`photo/?out=laser`（照片雷雕）、`photo/?out=litho`（3D 透光片）。
- **老師模式**：每個作品的參數、時間估算、備課小抄；學習單 PDF、機器校正；舊版作品（還沒依新規劃調整）。

不用安裝，手機、平板、筆電、桌電、Chromebook 都能開，也可以加到主畫面。照片和畫的圖只在這台裝置處理，不會上傳；草稿和電腦號碼只存在這台裝置的瀏覽器裡。有新版本時畫面上方會提示重新整理。

舊網址 https://kenchen0728.github.io/dongang-maker/photo/ 會自動轉到這裡。
