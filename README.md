# 創客小幫手

創客課程用的網頁小工具，不限課程或場地。目前的功能是「照片」：拍照或選照片，自動做成雷射雕刻或 3D 列印的檔案。

- 網址：https://kenchen0728.github.io/maker-helper/
- **雷射雕刻**：裁成圓形、愛心、方形或長方形，做成吊飾、立牌或純圖案 → 下載 SVG（照片 250 DPI 點陣＋紅色切割線），在 Beam Studio 雕刻、切割。
- **3D 透光片**：暗的地方印得厚、亮的地方印得薄，放在燈前才看得到照片；弧形立牌、立牌、吊飾或純圖案 → 下載 STL。網址加 `?out=litho` 直接開透光片。

不用安裝，手機、平板、筆電、桌電、Chromebook 都能開，也可以加到主畫面。照片只在這台裝置處理，不會上傳或儲存；記住的只有形狀、大小這些選項。

立牌底座的插槽寬度，讀同一個網站「[課程工具箱](https://kenchen0728.github.io/dongang-maker/courses/) → 機器設定」量到的數字（存在瀏覽器裡）。

之後要加的功能：手繪線稿（把線稿轉檔小幫手搬過來）、打字＋貼紙＋手繪。

舊網址 https://kenchen0728.github.io/dongang-maker/photo/ 會自動轉到這裡。
